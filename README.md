# KIN — אפליקציית כושר משפחתית 🏋️

אפליקציית כושר ביתי (PWA) למשפחה ולחברים: אימוני קליסטניקס מותאמים אישית,
מעקב אימונים ומשקל, מעקב תזונה, וטבלת ליגה משפחתית — הכל במקום אחד.

**זו גרסת MVP** — הבסיס שממנו גדלים למערכת ברמה בינלאומית.

---

## מה יש כרגע (גרסה 1)

- **אונבורדינג חכם** — גיל, מין, משקל, גובה, רמה, מטרה, וציוד → תוכנית מותאמת אישית.
- **בית / דשבורד** — האימון של היום, רצף (streak), סטטיסטיקות, והצצה לטבלה המשפחתית.
- **אימון פעיל** — מסך אימון עם סטים, חזרות, טיימר מנוחה, ומעקב התקדמות.
- **ספריית תרגילים** — הוראות ביצוע צעד-צעד, טעויות נפוצות, והתאמה (קל/קשה יותר) לכל תרגיל.
- **מעקב משקל** — גרף התקדמות.
- **תזונה** — יעד קלוריות ומאקרו (מחושב אישית) + מאגר מזון בסיסי.
- **משפחה** — טבלת ליגה ואתגר שבועי (דמו).
- **PWA מלא** — מתקינים למסך הבית, עובד גם בלי אינטרנט.

הנתונים נשמרים מקומית במכשיר (localStorage) — אין צורך בשרת כדי להתנסות.

---

## איך מריצים מקומית

```bash
# מכל שרת סטטי, למשל:
python3 -m http.server 8080
# ואז לפתוח בדפדפן:  http://localhost:8080
```

> חשוב: יש לגשת דרך `http://localhost` (או `https`) ולא לפתוח את הקובץ ישירות,
> כדי שה-Service Worker וההתקנה יעבדו.

## איך המשפחה "מורידה" בלי אפסטור

1. מעלים את התיקייה לאירוח סטטי חינמי (Vercel / Netlify / GitHub Pages) — מקבלים קישור `https`.
2. שולחים את הקישור למשפחה.
3. באייפון: Safari ← כפתור שיתוף ← "הוסף למסך הבית".
   באנדרואיד: Chrome ← תפריט ← "התקן אפליקציה".
4. מקבלים אייקון על המסך שנפתח כמו אפליקציה רגילה.

## מבנה הקוד

| קובץ | תפקיד |
|------|-------|
| `index.html` | שלד הדף |
| `styles.css` | מערכת העיצוב (dark, RTL) |
| `data.js` | ספריית תרגילים, מאגר מזון, ומחולל האימונים |
| `app.js` | כל הלוגיקה, המסכים והניווט (SPA) |
| `manifest.json` + `service-worker.js` | מה שהופך ל-PWA מותקן |
| `icon.svg` | אייקון האפליקציה |

## מפת דרכים (שלבים הבאים)

- **שלב 2:** חשבונות אמיתיים + סנכרון בענן (Supabase) ← משפחה אמיתית חוצת-מכשירים.
- **שלב 2:** סרטוני וידאו אמיתיים לכל תרגיל (במקום ההדגמה המונפשת).
- **שלב 2:** חיבור למאגר מזון אמיתי (USDA / Open Food Facts — חינם) + סריקת ברקוד.
- **שלב 3:** מנוע התאמה שלומד מההתקדמות בפועל; פידבק על ביצוע דרך המצלמה.
- **שלב 3:** עטיפה לאפליקציה לאפסטור/גוגל-פליי (Capacitor) + מנגנון מנוי.

_שם עבודה: **KIN**. קל להחלפה — מופיע ב-`manifest.json`, `index.html` וכ-`brand` ב-`app.js`._
