# 🤖 מערכת סוכני AI לחקר השוק האמריקאי

מערכת קטנה ועובדת של "סוכני AI" שעושים בשבילך מחקר שוק אמיתי על השוק האמריקאי
(מחירים, מתחרים, ביקוש, הזדמנויות), ומפיקה דוח עם המלצות קונקרטיות.

המערכת בנויה כמו צוות קטן:

| סוכן | תפקיד |
|------|--------|
| 🧑‍💼 **מנכ"ל** | מקבל מטרה עסקית ומפרק אותה למשימות מחקר |
| 🔍 **חוקרים** | מחפשים באינטרנט נתונים אמיתיים (מחירים, מתחרים, פערים) |
| 📊 **דוח** | המנכ"ל מסכם הכל להמלצות קונקרטיות + צעדים ראשונים |

---

## ⚠️ קודם — האמת בלי כחל ושרק

- זו **לא מכונת כסף**. היא כלי מחקר שעוזר לך להחליט במה כדאי להשקיע.
- כדי להרוויח כסף עדיין צריך מוצר, לקוחות וזמן. שום סוכן לא עושה את זה בלחיצת כפתור.
- מה שהמערכת **כן** נותנת: חיסכון של שעות מחקר, ונתונים אמיתיים שעוזרים לבחור נכון.

---

## 📋 מה צריך לפני שמתחילים (פעם אחת)

1. **מחשב** עם חיבור לאינטרנט.
2. **Python** מותקן. בדיקה: פתח טרמינל/שורת פקודה והקלד `python3 --version`.
   אם אין — הורד מ-https://python.org (לחץ Download, התקן, סמן "Add to PATH").
3. **מפתח API של Anthropic**:
   - היכנס ל-https://console.anthropic.com
   - הירשם (חינם), ואז **Billing → הוסף קצת קרדיט** (אפילו $5 מספיק להמון בדיקות).
   - לחץ **API Keys → Create Key**, והעתק את המפתח (מתחיל ב-`sk-ant-`).
   - ⚠️ שמור אותו במקום בטוח — אל תשתף אותו עם אף אחד.

---

## 🚀 הפעלה צעד-צעד

פתח טרמינל (ב-Windows: "Command Prompt"; ב-Mac: "Terminal") ובצע:

**שלב 1 — היכנס לתיקיית הפרויקט:**
```
cd נתיב/לתיקייה/של/הפרויקט
```

**שלב 2 — התקן את הספרייה הדרושה (פעם אחת):**
```
pip install -r requirements.txt
```

**שלב 3 — הכנס את מפתח ה-API:**

ב-Mac / Linux:
```
export ANTHROPIC_API_KEY=sk-ant-הכנס-כאן-את-המפתח-שלך
```
ב-Windows:
```
set ANTHROPIC_API_KEY=sk-ant-הכנס-כאן-את-המפתח-שלך
```

**שלב 4 — הרץ את המערכת:**
```
python3 agents.py
```
המערכת תשאל אותך מה לחקור. הקלד תחום עסקי, לדוגמה:
> מכירת מוצרי טיפוח טבעיים אונליין בארה"ב

או שתעביר את התחום ישר בפקודה:
```
python3 agents.py "מכירת בקבוקי מים חכמים בארה\"ב"
```

**זהו!** המערכת תעבוד כמה דקות (החוקרים מחפשים באינטרנט), ובסוף:
- תדפיס את הדוח על המסך
- תשמור אותו לקובץ `report_<תאריך>.md` שתוכל לפתוח בכל עורך טקסט

## 💡 טיפים

- **רוצה תוצאות שונות?** פשוט הרץ שוב עם תחום אחר.
- **רוצה יותר/פחות עומק?** פתח את `agents.py` ושנה את `NUM_RESEARCH_TASKS` (ברירת מחדל 4).
- **כמה זה עולה?** כל הרצה עולה בדרך כלל סנטים בודדים עד כמה עשרות סנט,
  תלוי בכמות החיפושים. עקוב אחרי השימוש ב-console.anthropic.com.

## ❓ בעיות נפוצות

| בעיה | פתרון |
|------|--------|
| `command not found: python3` | נסה `python` במקום `python3` |
| `לא נמצא מפתח API` | חזור על שלב 3 — צריך להגדיר את המפתח בכל פעם שפותחים טרמינל חדש |
| `pip: command not found` | נסה `python3 -m pip install -r requirements.txt` |
| המערכת איטית | זה תקין — החוקרים מחפשים באינטרנט. תן לה כמה דקות |
